# 🤖 Agent on PC

بوت أوتوميشن للتحكم في جهاز الكمبيوتر من خلال واجهة شات.

## ✨ المميزات

- 🖱️ التحكم بالماوس (ضغط، ضغط مزدوج، كليك يمين)
- ⌨️ الكتابة بالعربي والإنجليزي
- 📱 فتح وإغلاق التطبيقات
- 📸 أخذ سكرين شوت
- 🔲 التحكم بالنافذ (تكبير، تصغير، إغلاق، تبديل)
- 🔄 اختصارات لوحة المفاتيح
- 📍 معرفة موقع الماوس وحجم الشاشة
- 🎨 واجهة ديسك توب حديثة وسهلة

## 🛠️ التثبيت

```bash
git clone https://github.com/YOUR_USERNAME/Agent-on-pc.git
cd Agent-on-pc
pip install -r requirements.txt
```

## 🚀 التشغيل

```bash
python main.py
```

## 📖 الأوامر المتاحة

| الأمر | الوظيفة |
|-------|---------|
| اضغط | ضغط على الموقع الحالي |
| اضغط 100,200 | ضغط على نقطة محددة |
| اضغط مرتين | ضغط مزدوج |
| كليك يمين | ضغط بالزرار اليمين |
| اكتب نص | كتابة نص بالإنجليزي |
| اكتب نص عربي | كتابة نص بالعربي |
| افتح chrome | فتح تطبيق |
| اغلق | إغلاق النافذة |
| كبّر | تكبير النافذة |
| صغّر | تصغير النافذة |
| تبديل | تبديل النافذة |
| سكرين شوت | أخذ صورة للشاشة |
| اختصار ctrl+c | اختصار لوحة مفاتيح |
| موقع الماوس | معرفة الموقع الحالي |
| حجم الشاشة | معرفة حجم الشاشة |
| مساعدة | عرض جميع الأوامر |
| خروج | إغلاق التطبيق |
